 What I learned
I learned how to turn a real workshop calculation into a Python program: taking inputs such as power rating, hours of use and cost per unit of energy, and calculating the total energy used and its cost. I learned to convert input with float() and to use try/except so the program does not crash when someone types a wrong value. I also learned that using functions and clear variable names makes the code easier to read and to fix.
